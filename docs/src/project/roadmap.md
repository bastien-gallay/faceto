# Roadmap

The narrative roadmap — rationale, seam clustering, shipped history — is maintained in
[`ROADMAP.md`](https://github.com/bastien-gallay/faceto/blob/main/ROADMAP.md) at the repository
root. Priority and ordering live in
[Project #2](https://github.com/users/bastien-gallay/projects/2); the capture surface is
[the issue tracker](https://github.com/bastien-gallay/faceto/issues).

The current direction: **the board as a single-player instrument**, with an agent as the second
participant — make editing direct and the board legible before adding new participants or new
diagram formats.
